### 🚗 Distance Calculation Example

One of the programs calculates the distance traveled by a car using:

**Distance = Speed × Time**

```python
speed = float(input("Enter speed of the car (km/h): "))
time = float(input("Enter time traveled (hours): "))

distance = speed * time

print("Distance traveled:", distance, "km")
```
